SIMPLE-PROJECT

A simple file-sharing web application built with HTML, CSS, JavaScript, and Firebase.

ABOUT

Simple-Project is a small web application created as a learning project to explore authentication, cloud storage, database integration, and user-generated content.

Users can sign in with their Google account, upload files with optional captions, and interact with posts through a simple social-media-style interface.

FEATURES

- Google account authentication
- File uploads
- Optional post captions
- Feed-based post display
- Trends section
- Personal post section
- User session handling
- Logout functionality
- Post management

TECHNOLOGIES

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firebase Cloud Firestore
- Firebase Cloud Storage

PROJECT STRUCTURE

Simple-Project/
├── index.html
├── script.js
└── style.css

FIREBASE

This project uses Firebase for its backend services:

- Firebase Authentication — handles Google account sign-in and user sessions.
- Cloud Firestore — stores application data.
- Cloud Storage — handles uploaded files.

PROJECT STATUS

This is a learning project and is currently a simple implementation of a Firebase-powered file-sharing application.

Future improvements may include additional social features, improved UI/UX, stronger validation, and better post management.
